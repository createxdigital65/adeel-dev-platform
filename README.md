# Adeel Sattar Personal Brand Platform

This repository contains the source code for a modern, professional personal brand platform built with Angular (frontend) and ASP.NET Core (backend). The project follows clean architecture principles and uses Tailwind CSS for styling.

## Project Structure
- `backend/` – ASP.NET Core API solution.
- `frontend/` – Angular application.
- `docker/` – Docker compose and Dockerfiles for containerization.

## Development
See the `README.md` files within `backend/` and `frontend/` for setup instructions.
